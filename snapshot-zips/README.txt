Put your snapshot zips here, named like the folder they came from but with
underscores instead of spaces:

    snapshots/horion 6-12-26/     ->   snapshot-zips/horion_6-12-26.zip

Each zip is just the zipped-up version of the matching folder in snapshots/.
The "download zip" link on each snapshot bubble points here.

(Zip the CONTENTS of the folder, so opening the zip drops you straight
into the project files - not into another nested folder.)
